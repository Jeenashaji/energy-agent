# Data

The raw data is not committed to git (see `.gitignore`).

1. Go to smard.de and open the market data download page.
2. Choose: wholesale prices (Großhandelspreise) · Germany/Luxembourg · a few months · CSV.
3. Save the file as `data/raw/prices.csv`.

`data/memory.sqlite` is created automatically: it stores conversation memory (checkpoints).
